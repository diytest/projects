3. A clamp for SMD components.

RADIO magazine, No. 3, 2005. Describes a clamp made from a ruling pen that is easy to make and convenient to use.

4. Making printed circuit boards for prototypes.

SKHEMOTEKHNIKA magazine, No. 6, 7, 8  2005. On preparing PCBs in P-CAD for production from a laser-printer printout transferred to the blank with an iron, on the features of a process that has been described many times before, on preparation - manufacturing, and aligning the two sides of the pattern.

5. Connecting External RAM to AVR Microcontrollers.

SKHEMOTEKHNIKA magazine, No. 10,11,12, 2005 and #1, 2006. Describes connecting a 512Kx8 external RAM chip to an ATMega8535 microcontroller, using buffers addressed as if they were external RAM memory cells.

6. Using the BF9864A Graphic LCD.

SKHEMOTEKHNIKA magazine, No. 2, 3, 4 2006. Presents a simple circuit built on an ATmega MCU, sufficient to connect a compact (1.6 x 25 x 30) 98 x 64-pixel graphic LCD, along with a program listing and description. The program shown lets you output several characters to the LCD and demonstrates plotting a simple graph.

7. Multiplexed Display on 7-Segment LED Indicators.

SKHEMOTEKHNIKA magazine, No. 5, 6 2006. The article describes the principle of dynamic control and character generation on a multi-digit display; it describes a device built on an ATmega microcontroller driving a 9-digit indicator, and provides a listing and description of the running-text program.

8. Book "AVR MICROCONTROLLERS: ALGORITHMS, CIRCUITS, PROGRAMS" with a CD.

Second edition. DODEKA XXI Publishing, Moscow-2005. Corrected errors that occurred during prepress preparation of the figures. The CD contains listings of the programs discussed in the book.

9. Working with Atmel AVR Microcontrollers.

SKHEMOTEKHNIKA magazine, No. 8, 9, 10, 11, 12 2006. Using a simple alarm-controller project (several buttons, contactors, a siren, LEDs) as an example, it covers working with the AVR Studio 4.12 development environment from the basics.

10. Mounting a Magnifier on a Desk Lamp.

RADIOLYUBITEL magazine, No. 9, 2006 . A simple fixture for mounting a large-diameter magnifier on a desk lamp. 

11. Book "AVR MICROCONTROLLERS: ALGORITHMS, CIRCUITS, PROGRAMS" with a CD.

Third edition, expanded and revised. DODEKA XXI Publishing, Moscow-2006.

On the layout of the CD for the 3rd edition:
unfortunately, the CD-ROM layout produced by the editors does not match the original text and layout,
the CD-ROM folders indeed do not open from the disc's menu.
To open the project folders,
-open "My Computer",
-find the drive "Dodeca (<drive letter>:)" there (for example, "Dodeca(E:)")
-right-click on this drive and choose "Open" from the menu that appears
as a result, an Explorer window will open showing the contents of the CD-ROM
-go into the Files folder, and inside it, into the Source folder. All the source files are located in this folder (<drive letter>:\Files\Source\)
-the source files for the projects illustrating COM-port operation are located here as well, in the folder <drive letter>:\Files\Source\COM_port\

12. Using the CP2102 USB-UART Bridge.

SKHEMOTEKHNIKA magazine, No. 3, 4 2007. The article gives recommendations for hand-soldering a QFN package with no leads extending beyond the package outline, and tips for testing the soldering results; it gives an illustrated description of driver installation, and provides an example of Delphi functions that determine the number of the virtual COM port created when the drivers are installed.

13. Using the Microcontroller's USART to Communicate with a Computer.

SKHEMOTEKHNIKA magazine, No. 6, 7, 8, 9 2007. Variants of level-converter circuits, including an opto-isolated one with a transfer rate up to 115200 bit/s, are covered; variants for writing the software for the microcontroller and the computer application are discussed, both using ready-made components and using Windows API functions directly.

15. Connecting Programmers to a Controller Board.

SKHEMOTEKHNIKA magazine, No. 10, 2007. Designs are presented for homemade connectors that make it easier to repeatedly connect a programmer to the controller during debugging, eliminating the need to install a connector on the board for programming.

16. Recovering the Configuration of AVR Microcontrollers.

Radio magazine, No. 11, 2009. Has an AVR microcontroller stopped being programmable? The article describes how to restore the microcontroller's Fuse bits so that it can be programmed again.
